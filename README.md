One absurd-but-believable weather line for an invented city, read deadpan,
for the [make.fun bounty](https://make.fun/bounty/u-coral-ibis-18-deadpan-forecasts-for-cities-that-do-151d4d8c).

## Entry

> In Crumblecote, hail the size of peas, falling politely in single file. 11 degrees, 30 percent chance of queueing.

114 characters (Python `len()`), inside the 1–160 gate. Crumblecote does not
exist. The joke is one mechanism, not a pile: the hail is polite — it falls
in single file, so the forecast can only offer a 30 percent chance of
queueing. Concrete detail (pea-sized hail, 11 degrees, 30 percent) makes the
place feel real; the tone is a straight-faced broadcast line.

## How it runs

`main.ts` (Node.js standard library only) writes the fixed entry string to
`$ENTRY_OUTPUT`, or `/output/entry.txt` when unset. No network, no
randomness — both graded runs produce byte-identical output.
